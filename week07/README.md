# 第七周：RNN 与 LSTM 序列预测

本周继续用 ETTh1 的油温（`OT`）做"过去 24 小时 → 下一小时"的预测，模型从线性回归 / MLP
换成 **RNN 与 LSTM**。重点不是刷分，而是看清三件事：

1. 同一套参数怎样沿时间反复使用（循环连接、参数共享）；
2. 损失只在末端算一次，梯度怎样沿展开的计算图传回早期时间步；
3. LSTM 在隐藏状态之外多了细胞状态和三个门，它们各自负责什么。

两个实践：

- **实践一**：5 步标量 RNN，手工可核对的前向 + 一次反向，观察梯度和输入顺序的影响；
- **实践二**：单层 LSTM（H=16 / 32）完成同一预测任务，与上周基线比较。

## 2. 组件划分与接口设计

| 文件 | 职责 |
|---|---|
| `data.py` | 读 CSV、完整性检查、`make_windows`、按目标时刻划分、训练时段 μ/σ、整理成 `(N,24,1)` |
| `small_rnn.py` | 实践一核心：5 步前向、单次反向、顺序对照、手算核对与小算例 |
| `models.py` | `LSTMRegressor`（LSTM + 线性输出层）、形状检查、参数统计、两种上周基线 |
| `training.py` | DataLoader、完整评分的 MSE、40 轮训练循环、最佳轮次保存 |
| `evaluation.py` | 原始尺度 MAE / RMSE、从逐条预测重算指标 |
| `reporting.py` | 保存 CSV / 模型文件，绘制两张图 |
| `run_small_rnn.py` | 实践一入口 |
| `run_lstm.py` | 实践二入口 |

**一个关键接口的设计理由**：`LSTMRegressor` 同时提供 `forward` 和 `forward_with_states`。

- `forward(x)` 只返回 `(B,1)` 的预测，训练循环用它，接口干净；
- `forward_with_states(x)` 额外返回序列输出、`h_n`、`c_n`，专门给"看形状/看状态"用。

这样训练代码不用为了打印形状而改签名，观察代码也不用重新实现一遍 LSTM 调用。
两个入口互不依赖：`python run_small_rnn.py` 和 `python run_lstm.py` 可以分别运行。

## 4. 实践一：展开一个小 RNN

### 4.1 数据与公式

取最前面 6 小时，`z[k] = (u[k] - u[1]) / 10`（基准固定为第一条油温）：

| k | 时间 | u[k] | z[k] |
|---|---|---|---|
| 1 | 2016-07-01 00:00 | 30.531 | 0.0000 |
| 2 | 2016-07-01 01:00 | 27.787 | −0.2744 |
| 3 | 2016-07-01 02:00 | 27.787 | −0.2744 |
| 4 | 2016-07-01 03:00 | 25.044 | −0.5487 |
| 5 | 2016-07-01 04:00 | 21.948 | −0.8583 |
| 6 | 2016-07-01 05:00 | 21.174 | −0.9357（目标） |

计算：`h[k] = tanh(wx·z[k] + wh·h[k-1] + b)`，`h[0]=0`，`wx=0.6, wh=0.5, b=0`，
`预测 = 0.8·h[5] + 0.1`，`损失 = (预测 − z[6])²`。

### 4.2 五步前向（参数只有一组）

| 步 | 原下标 | z | h_prev | wx·z | wh·h_prev | h |
|---|---|---|---|---|---|---|
| 1 | 0 | 0.0000 | 0.0000 | 0.0000 | 0.0000 | 0.0000 |
| 2 | 1 | −0.2744 | 0.0000 | −0.1646 | 0.0000 | −0.1632 |
| 3 | 2 | −0.2744 | −0.1632 | −0.1646 | −0.0816 | −0.2414 |
| 4 | 3 | −0.5487 | −0.2414 | −0.3292 | −0.1207 | −0.4218 |
| 5 | 4 | −0.8583 | −0.4218 | −0.5150 | −0.2109 | −0.6205 |

**末端**：预测 −0.3964，目标 −0.9357，**损失 0.2908**。

代码里只创建了 3 个参数张量，五步循环用的是同一组；每一步变化的是输入和状态，不是参数。
把五步画成五个框，每个框旁边标注的都是同一组 `wx / wh / b`。

### 4.3 一次反向：三个参数梯度 + 五个输入梯度

对上面这一次损失调用 `backward()`，**不调用优化器、不更新参数**：

| 参数 | 梯度 |
|---|---|
| ∂loss/∂wx | −0.616943 |
| ∂loss/∂wh | −0.293199 |
| ∂loss/∂b | +0.926310 |

| 步 | 原下标 | z | ∂loss/∂z |
|---|---|---|---|
| 1 | 0 | 0.0000 | +0.014993 |
| 2 | 1 | −0.2744 | +0.029987 |
| 3 | 2 | −0.2744 | +0.061613 |
| 4 | 3 | −0.5487 | +0.130850 |
| 5 | 4 | −0.8583 | +0.318343 |

三个要点：

1. **梯度不等于数值**。`z[1] = 0`，但它的梯度是 0.014993，不为 0——
   梯度看的是 tanh 在这一点附近的斜率，不是这个数本身的大小。
2. **越早的输入梯度越小**，但这不等于"它没参与计算"。它参与了，
   只是它的影响要多经过几层 tanh 和乘法才能到达末端，敏感程度自然更低。
3. **`wh` 被用了 5 次**（第 2~5 步各一次，第 1 步乘的是 h[0]=0，贡献为 0）。
   五处引用的是同一个参数，所以梯度汇集到同一个 `wh.grad` 上，不是五个独立参数。

`z[k]` 的梯度是损失对**已变换输入**的导数，不是对原始数据预处理过程求导。

### 4.4 手算核对第 2 步

```
h[1] = tanh(0.6 × 0.00000 + 0.5 × 0 + 0) = 0
h[2] = tanh(0.6 × (−0.27440) + 0.5 × 0 + 0)
     = −0.163168329      ← 手算
     = −0.163168329      ← 程序，差值 0
```

### 4.5 顺序对照 [1,4,3,2,5]

相同参数、同样从零状态开始，只做前向：

| 步 | 原顺序 输入/上一状态/新状态 | 对照序 输入/上一状态/新状态 |
|---|---|---|
| 1 | z1=0.0000 / 0.0000 / 0.0000 | z1=0.0000 / 0.0000 / 0.0000 |
| 2 | z2=−0.2744 / 0.0000 / −0.1632 | z4=−0.5487 / 0.0000 / −0.3178 |
| 5 | z5=−0.8583 / −0.4218 / −0.6205 | z5=−0.8583 / −0.3104 / −0.5851 |

末端预测：原顺序 −0.396435，对照序 −0.368081，差 −0.028355。

**最后一步的输入相同，但上一状态不同，所以末端状态不同。**
这正说明历史是通过"状态逐步传递"进入计算的，而不是只看最后一个输入。
若两组末端结果很接近，也不能就此说模型没考虑顺序——要沿中间状态逐项比较。

### 4.6 两个帮助理解的展开

**去掉 tanh 后的前两步**：

```
h[1] = wx·z[1]
h[2] = wx·z[2] + wh·h[1] = wx·z[2] + (wh·wx)·z[1]
```

代入 wx=0.6、wh=0.5：z[1] 的系数 0.300，z[2] 的系数 0.600。
参数固定时，预测只是输入的**一次函数**，没有 z[1]·z[2] 这种输入乘积。
参数之间相乘（wh·wx）是常数，不等于对输入有非线性——这正是 MLP 层间需要激活函数的原因。

**梯度连乘小算例**：每步乘 0.5，2 步后 0.25、5 步后 0.03125、10 步后约 0.00098；
每步乘 1.5，5 步后约 7.59。真实 RNN 的局部导数还取决于权重和 tanh 的导数，
这里只说明"路径越长，信号要经过的变换越多"。

## 5. 实践二：LSTM 预测下一小时

### 5.1 形状与参数数量（训练前用 8 条真实验证样本检查）

| 张量 | H=16 | H=32 | 含义 |
|---|---|---|---|
| 输入 `input` | (8, 24, 1) | (8, 24, 1) | 批大小、时间步、每步特征数 |
| 序列输出 `output` | (8, 24, 16) | (8, 24, 32) | 每个时间步都有一个隐藏表示 |
| 最终隐藏 `h_n` | (1, 8, 16) | (1, 8, 32) | 第 0 维是"层数 × 方向数"，单层单向 → 1 |
| 最终细胞 `c_n` | (1, 8, 16) | (1, 8, 32) | 与 `h_n` 同形状 |
| 预测 `pred` | (8, 1) | (8, 1) | 每条窗口一个预测值 |
| 可训练参数 | **1233** | **4513** | LSTM 1152 + 输出层 17 / LSTM 4352 + 输出层 33 |

LSTM 参数公式：`4 × H × (1 + H + 1)`（四组门变换，输入维 1、隐藏维 H、每组一个偏置），
输出层 `H × 1 + 1`。

已用张量核对：**单层单向时，`output[:, -1, :]` 与 `h_n[-1]` 完全相等**（`allclose` 通过）。
所以"取末步序列输出"和"取最终隐藏状态"是同一件事。

`h_n` 和 `c_n` 不是一回事：`h` 是本步对外提供的表示（还要参与下一步的门控计算），
`c` 是内部细胞状态。`h = o ⊙ tanh(c)`，如果把 `c` 直接送进输出层，就绕过了输出门和 tanh。

### 5.2 训练结果

两组都训练 40 轮，Adam（lr=0.001，weight_decay=0），batch=128，MSE 在标准化目标上。

| 模型 | 最佳轮次 | 最佳验证 MSE（标准化） | 验证 RMSE（原始尺度） |
|---|---|---|---|
| lstm_h16 | 38 | 0.009931 | 0.914 |
| lstm_h32 | 39 | 0.009924 | 0.914 |

两组几乎打平，**选定 H=32**（未取整的验证 RMSE 略低；完全相同才按规则选 16）。
选定后只对 H=32 做测试评价，不再合并训练验证集重训。

### 5.3 指标汇总（`metrics.csv`）

| 模型 | 训练 RMSE | 验证 RMSE | 测试 RMSE | 说明 |
|---|---|---|---|---|
| last_value | 1.067 | 0.925 | 0.593 | 不学参数 |
| lag_linear | 1.043 | **0.910** | **0.585** | 24 个权重 + 偏置 |
| lstm_h16 | 1.052 | 0.914 | — | 未选中，不评测试 |
| **lstm_h32（选定）** | 1.047 | 0.914 | 0.609 | 4513 个参数 |

MAE 见 `results/metrics.csv`（选定 LSTM：训练 0.720 / 验证 0.598 / 测试 0.449）。

### 5.4 一个具体目标：窗口怎样变成末步表示

目标时刻 **2017-06-28 12:00**（原下标 8700）：

1. 取它之前 24 小时的真实 OT（20.54 → 21.32），标准化成 `(1,24,1)`；
2. LSTM 逐步读 24 步，每步更新 `(h, c)`，最终得到 `h_n`、`c_n`，形状 `(1,1,32)`；
3. 取最后一步的隐藏表示 `(1,32)`，前 5 个分量是
   `[0.544, −0.646, 0.101, 0.527, −0.039]`；
4. 线性输出层把它映射成一个标准化预测 **+0.4768**；
5. 还原：`0.4768 × 9.1765 + 17.1283 = 21.504`，**真实值 21.456**。

这个 32 维向量不是某一小时的油温，也不是 PCA 那样的方差方向，
而是模型为了降低预测误差、在递推过程中学出来的中间量。

## 6. 基线来源与观察

- `last_value`：直接用最近一次观测，不学参数。
- `lag_linear`：把 24 个历史值当 24 个特征，`StandardScaler + LinearRegression`。

两者都用**原始油温和自己的预处理**，不套用 LSTM 的 μ/σ；训练范围与 LSTM 一致
（同一批 8616 条训练窗口）。这三种口径在本文件内重新计算并核对过，
与第六周 `metrics.csv` 的数值一致（0.925 / 0.910）。

**主要观察**：

1. **LSTM 没有超过线性基线**：验证 0.914 vs 0.910，测试 0.609 vs 0.585。
   这与第六周的结论一致——一小时预测中，"最近值"几乎包含了全部信息。
2. **验证 MSE 低于训练 MSE** 不是过拟合，而是时段差异：训练段跨两个夏天
   （OT 波动大），验证段波动小（第六周已统计：训练 σ 9.19、验证 4.97、测试 3.15）。
3. **测试变差值得注意**：LSTM 验证 0.914 → 测试 0.609（RMSE 恶化），
   而线性模型 0.910 → 0.585。冬季数据只有 2880 条，LSTM 的 4513 个参数
   更容易受分布差异影响；但单次结果不足以定论。
4. **成绩接近不能证明"学会了长距离依赖"**。LSTM 完全可能只利用了最近两三步。
   要区分三个层次：结构上**能够**接收早期信息 → 预测对早期信息**敏感** →
   这些信息**改善了**预测。本次结果只支持前两个层次的部分判断，
   第三个层次需要专门设计"只用最近 6 小时 vs 完整 24 小时"的对照实验（本次未做）。
5. **新信息写入靠门控，但门值没有标签**。损失只在末端算一次，
   梯度经 `c` 的直接路径和 `h` 的门控路径传回各时间步，
   sigmoid/tanh 的权重就是这样被训练出来的——没有人为标注"这一步该记多少"。

## 7. 局限

- 只训练单层单向 LSTM，没有比较层数、双向、dropout 的影响。
- 每个窗口都从零状态开始，不跨窗口传递状态（任务要求如此）。
- 24 个小时全部压缩进一个固定维度的末步表示，哪些信息被弱化无法直接观察。
- 未做"窗口长度 6 vs 24"的对照，所以**不能**从本次结果推断历史范围的作用。
