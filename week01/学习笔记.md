# 第一周学习笔记：机器学习入门与 vibe coding 工具配置

## 一、知识点理解（结合 diabetes 数据集）

以下用本周的糖尿病数据集举例，形成自己的理解，而不是背定义。

| 知识点 | 我的理解 |
|---|---|
| **机器学习** | 从数据里"学"规律，而不是手写规则。比如不写"如果 bmi>30 病情就重"这种固定规则，而是让模型从 442 条数据里自己发现 bmi 和 target 的关系。 |
| **监督 vs 无监督** | 关键看有没有"标签"。diabetes 有明确的 `target` 标签，是**监督学习**；无监督学习没有标签，比如把患者自动聚成几类。 |
| **回归 vs 分类** | 回归预测**连续数值**（diabetes 的 target 是 25~346 的连续值）；分类预测**离散类别**（如"高危/低危"）。不能只看标签是不是数字：0/1 编码的类别也是数字，但属于分类。 |
| **样本、特征、标签** | 样本 = 一行数据（一个患者）；特征 = 输入的 10 列（age、bmi…）；标签 = 要预测的 `target`。 |
| **模型与参数** | 模型是把输入变成输出的规则（如线性回归 y = w·x + b）；参数是训练中不断调整的量（w、b）。 |
| **训练 vs 预测** | 训练 = 用数据调整参数；预测 = 用学好的参数处理**没见过的新数据**。 |
| **损失函数 vs 评价指标** | 损失函数在训练时指导模型"往哪改"（如均方误差）；评价指标衡量"最终好不好"（如 R²）。两者有时可以用同一个量（MSE 既可作损失也可作评价）。 |
| **训练/验证/测试集** | 训练集学参数，验证集调超参/选模型，测试集做最终评估。区分它们是为了诚实评估模型对**新数据**的表现。 |
| **泛化与过拟合** | 泛化 = 在新数据上也好；过拟合 = 记住了训练数据的噪声，训练集表现好、新数据上变差。 |

## 二、铁路项目思考题

- **"预测下一次检测的某个数值"** → **回归任务**。
  样本 = 一次检测记录；特征 = 这次检测到的各项指标（如温度、振动、电压）；标签 = 下一次检测的目标数值。
- **"判断一段波形属于哪一类"** → **分类任务**。
  样本 = 一段波形；特征 = 从波形提取的量（幅值、频率、峰度等）；标签 = 波形类别（如正常/某类故障）。

## 四、实践记录

### 环境
Python 3.14.5 + pandas 3.0.3 + matplotlib 3.11.1 + scikit-learn 1.9.0。

### 数据观察
- 442 行 × 11 列，10 个特征 + 1 个目标 `target`。
- 无缺失值。
- target 范围 25~346，均值 152.1，标准差 77.1。

### 绘图
1. `target` 分布直方图（30 个分箱）。
2. 特征与目标散点图。

### 一次有目的的修改（bmi → age）
- **修改**：把散点图特征从 `bmi` 换成 `age`。
- **预期**：以为 age 与 target 仍有线性上升，且年龄越大点越密。
- **实际**：age 与 target 相关系数仅 **0.188**，远低于 bmi 的 **0.586**，散点图几乎无趋势；age 分布均匀，无密集区。
- **收获**：
  1. 不能用直觉（"年龄越大病情越重"）替代数据。
  2. 相关性和分布密度是两回事。
  3. 特征选择很重要——bmi 明显比 age 更能预测 target。
